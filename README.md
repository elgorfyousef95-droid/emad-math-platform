# منصة مستر رياضيات عماد السنافيري

منصة تعليمية عربية RTL مبنية باستخدام React وVite.

## الأقسام المخططة
- واجهة الطالب: الرئيسية، الكورسات، المحاضرات، الملفات، الواجبات، الامتحانات، النتائج، الجدول، الملف الشخصي، خدمة العملاء.
- لوحة المستر: إدارة المحتوى التعليمي والواجبات والامتحانات والدرجات.
- لوحة المالك: إدارة الحسابات والصلاحيات والاشتراكات والإعدادات والتقارير.
- قاعدة البيانات: Supabase مع سياسات RLS وصلاحيات يتم التحقق منها على الخادم.

## ملاحظة أمان
واجهات تسجيل الدخول ولوحات الإدارة الحالية نماذج واجهة أولية فقط. لا تعتمد عليها لتسجيل بيانات حقيقية أو منح صلاحيات قبل إكمال نظام المصادقة والتحقق الخادمي وربط Supabase.
